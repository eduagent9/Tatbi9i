# تطبيقي

تطبيق عربي مستقل لإدارة نشاط تجاري ومخزون ونقطة بيع.

## النسخة الحالية
- لوحة قيادة ومؤشرات المبيعات والمخزون.
- إدارة المنتجات والأسعار والكميات وصور المنتجات.
- نقطة بيع وسلة وفواتير مع الأداء النقدي أو الجزئي أو بالدين.
- سجل الفواتير وطباعة الفاتورة.
- إدارة الزبناء والموردين.
- حركات المخزون والمصاريف والتقارير.
- تصدير المنتجات CSV ونسخ احتياطي/استرجاع JSON.
- واجهة RTL متجاوبة مع الهاتف، ودعم التثبيت كتطبيق ويب PWA.
- تخزين محلي مستقل بمفتاح `tatbiqi.database.v1`.

## التشغيل
افتح `index.html` عبر خادم HTTPS أو localhost للحصول على أفضل دعم لـ PWA. البيانات تبقى في المتصفح والجهاز الحالي؛ النسخ الاحتياطي ضروري قبل تغيير الجهاز أو مسح بيانات المتصفح.

## المرحلة التالية
اختبار الوظائف، تحسين حماية الحسابات والصلاحيات، مزامنة اختيارية، ثم إعداد نسخة Android APK عبر Capacitor.
